ditto_flutter_tools 3 supports Ditto Flutter SDK 5 and requires `ditto_live` 5.0.1 or a later 5.x release.

## Breaking changes

- Ditto Flutter SDK 4 is no longer supported. Applications must migrate their Ditto initialization and SDK usage to Ditto 5 before adopting this tools major.
- `SyncStatusHelper`, `SyncStatusView`, and `SyncStatus` were removed because subscription timing did not reliably represent synchronization progress. `PeerSyncStatusView` remains available for inspecting per-peer sync status.

## Changed

- Removed the obsolete `DITTO_WEBSOCKET_URL` example setting. Ditto 5 derives the server WebSocket endpoint from the authentication URL. (SDKS-3929)

## Fixed

- `PeerSyncStatusView` now loads per-peer sync information with Ditto 5 instead of remaining on the loading screen. (SDKS-4636)
